# ARNIX IPTV — Smotru.tv parser

Скрипт `viks_parser.py` теперь использует каталог телеканалов `https://smotru.tv/` и создаёт `smotru.m3u`.

## Автообновление

GitHub Actions запускает сбор каждые 6 часов или вручную через **Actions → Update Smotru IPTV playlist → Run workflow**.

Плейлист:
`https://raw.githubusercontent.com/arnix858-lang/ARNIX-IPTV/main/smotru.m3u`

## Что делает сборщик

- Читает публичный каталог Smotru.tv и ссылки на страницы каналов.
- Использует Playwright/Chromium для наблюдения за HLS/DASH-запросами, которые браузер делает при обычной загрузке страниц.
- Добавляет только явно обнаруженные ссылки на манифесты .m3u8/.mpd.
- Не обходит авторизацию, DRM, платный доступ или другие ограничения.
- Успешный запуск не гарантирует, что каждый канал доступен во внешнем IPTV-плеере: ссылки могут быть временными или требовать поддерживаемых сайтом условий воспроизведения.

Для EPG скрипт ищет JSON-LD BroadcastEvent; если сайт не предоставляет такие данные, XMLTV не создаётся.
