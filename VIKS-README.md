# ARNIX IPTV — Viks.tv parser

Скрипт `viks_parser.py` собирает список страниц каналов с `https://live.viks.tv/tv3/`, ищет на страницах **прямые публичные** HLS/DASH-манифесты (`.m3u8` / `.mpd`) и создаёт `viks.m3u`.

## Автообновление

GitHub Actions запускает парсер каждые 6 часов. Можно запустить вручную:

1. Откройте вкладку **Actions** репозитория.
2. Выберите **Update Viks IPTV playlist**.
3. Нажмите **Run workflow**.
4. После успешного запуска плейлист будет доступен по адресу:

`https://raw.githubusercontent.com/arnix858-lang/ARNIX-IPTV/main/viks.m3u`

Если сайт публикует распознаваемые данные телепрограммы в JSON-LD `BroadcastEvent`, скрипт дополнительно создаст `viks_epg.xml`. Если на странице телепрограммы нет расписания или сайт сообщает, что программа отсутствует, XMLTV не создаётся.

## Запуск на Android (Termux / Pydroid 3)

Python 3.9+; дополнительные библиотеки не нужны.

```bash
python viks_parser.py
```

Можно ограничить число страниц:
```bash
VIKS_MAX_CHANNELS=30 python viks_parser.py
```

## Важно

- Скрипт не взламывает плееры, не обходит авторизацию, DRM, подписки и ограничения доступа.
- Он добавляет только прямые ссылки на медиаманифесты, которые сайт открыто отдаёт в HTML/конфигурации плеера.
- Наличие URL в M3U не гарантирует, что канал будет воспроизводиться: некоторые ссылки могут быть временными, привязанными к сессии, региону или сайту.
- GitHub хранит текст плейлиста, но не ретранслирует видео.
- Используйте потоки только если у вас есть право на их просмотр и распространение.
